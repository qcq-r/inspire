This GitHub repository is to store my re-analysis in R of Takaaki Yuguchi's InSPIRE work.

Samples: Plasma from R03 cohort (Ivo Mueller, PLOS One, 2011) of 185 PNG children aged 1-3 years
IgG, IgG1, IgG3, C1q, FcgRI, FcgRII, FcgRIII: Multiplex immunoassay (MAGPIX)
Grouping: Antibody responses classified into 3 groups (G1, G2, G3) in ascending magnitude of response 
          using covidClassifyR shiny app (https://shaziaruybal.shinyapps.io/covidClassifyR/)

Antibody data used based on "InSPIRE_collated_RAU_MFI.xslx" and metadata "c1R03_complete_newAGE.dta", converted to .csv
